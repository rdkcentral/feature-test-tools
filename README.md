# feature-test-tools
Application tools for testing functionality within RDKM middleware images

## 1. ralfinfo
Application to test the RALF bundle related features.

## 2. AOWS Voice Test Server
A sample AOWS Voice Test Server which can be used to test the RDK Voice Integration. See [ReadMe](./aowss-voice-test-server/README.md) for more details.

## 3. Firebolt Test App
2 variants of test applications for validating Firebolt functionality. See [WebAppReadMe](./firebolt-test-app/web/README.md) and [NativeAppReadMe](./firebolt-test-app/native/README.md) for more details.

## 4. App Manager Test App
Simple COMRPC-based test app to check various App Manager functionalities. Refer to [ReadMe](./ramtapp/README.md) for more details.
